# Forma Studio — Interior Design Website

A responsive Next.js App Router starter for a premium interior design studio.

## Stack
- Next.js 15 + React 19
- TypeScript
- Tailwind CSS v4 (with custom CSS for the editorial layout)
- Lucide icons
- Next/Image for project photography

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize
- Edit `src/app/page.tsx` to change studio copy, project names, services and contact details.
- Replace the Unsplash image URLs with your own project photography.
- Update the metadata in `src/app/layout.tsx`.
- Adjust colors, typography and responsive styles in `src/app/globals.css`.

The contact links currently use a placeholder email address (`hello@formastudio.example`). Replace it before launch.

## Production build

```bash
npm run build
npm run start
```
